🔧 Flask Backend Integration

To connect to a Flask backend:

  1. Install Flask dependencies: pip install -r requirements.txt
  2. Run the example backend: python flask-backend-example.py
  3. Update frontend API settings in js/utils/api.js:
    this.baseURL = 'http://localhost:5000/api';
    this.mockMode = false;
  4. Restart the frontend
